SteadyClip is a Sharpe-first paper-trading bot for pump.fun bonding curves. It is ranked by hourly Sharpe ratio on a 6-hour forward replay, so it trades for many small, uniform, realised wins instead of moonshots: equal small stakes, one buy per coin on a confirmation filter (a launch that is already hot a few slots after creation), an early take-profit via a tight trailing stop, fast stop-losses, and a short max hold. A probe mechanism tops the distinct-coin count toward the 20-coin guardrail with tiny 0.01 SOL round trips when needed. Deterministic: no clock, no environment, no randomness.

## Run it

```sh
node main.ts
```
